# Карта CLM-решений

Интеллект-карта LegalTech-кластера «Договорная работа / CLM».

- `CLM-mindmap.pdf` — одностраничная диаграмма (A3, альбомная). Структура: CLM → 4 класса решений → 11 продуктов. В карточке каждого продукта: кому подходит, эффект, цена и срок внедрения, интеграции, проблемы внедрения, а также полоска покрытия 6 этапов жизненного цикла договора.
- `presentation-outline.md` — тезисы на 6 слайдов с теми же цифрами.
- `pdf/` — исходник диаграммы. Чтобы пересобрать PDF, откройте `pdf/mindmap-print.html` в Chromium и напечатайте в PDF (A3, альбомная, без полей).

Цены взяты из открытых источников (октябрь 2026), источники указаны внизу диаграммы. Сроки с пометкой «≈» — оценка.
