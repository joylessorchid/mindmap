# Карта CLM-решений

Интеллект-карта LegalTech-кластера «Договорная работа / CLM» для задания по LegalTech.

- `index.html` — интерактивная карта в одном файле, без сборки. Структура карты: CLM → 4 класса решений → 11 продуктов → экосистема интеграций. На каждом продукте полоска покрытия 6 этапов жизненного цикла договора. Клик по продукту открывает карточку: для кого, эффект, цена, срок, интеграции и проблемы внедрения. Ниже на странице таблица сравнения, рекомендации по стеку и чек-лист для демо.
- `presentation-outline.md` — тезисы на 6 слайдов с теми же цифрами.

Чтобы открыть карту, откройте `index.html` в браузере или включите GitHub Pages (Settings → Pages → ветка, папка `/`).

Цены взяты из открытых источников (октябрь 2026), ссылки собраны внизу страницы. Сроки с пометкой «оценка» нужно подтверждать у вендора.
